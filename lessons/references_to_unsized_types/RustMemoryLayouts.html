Closures — анонимная структура + impl Fn*

Замыкание — это не «функция в куче». Компилятор генерирует уникальную безымянную структуру, в поля которой кладёт захваченные переменные, и реализует для неё Fn / FnMut / FnOnce. Размер замыкания = размер этой структуры. Сама по себе она живёт на стеке; в кучу она попадает только если вы явно положите её в Box, Rc, Vec…

|| a as i64 + b 16 bytes 
let a = 10i32;
let b = 20i64;
let by_ref = || a as i64 + b;

// компилятор генерирует примерно это:
struct __Closure<'a> { a: &'a i32, b: &'a i64 }
impl Fn() -> i64 for __Closure { fn call(&self) -> i64 { *self.a as i64 + *self.b } }

Сложные аллокации — Box, Rc, вложенные буферы

Ссылки на структуры

Ссылки на массивы и слайсы

Массив [T; N] — значение, N элементов подряд, длина — часть типа. Поэтому &[T; N] — thin (8 B). Слайс [T] — unsized, длина известна только в runtime, поэтому &[T] — fat (ptr + len, 16 B). Все ссылки ниже указывают в один и тот же массив.
